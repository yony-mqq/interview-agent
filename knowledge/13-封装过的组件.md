# floating-sheet 面试稿

## 一句话总结

`floating-sheet` 是一个基于 Rax 的底部浮层面板组件，核心解决了「手指拖拽、多档位吸附、内部滚动冲突、跨端渲染」四个问题，通过 `translateY` 位移动画 + `ref` 实时高度 + `scrollIds` 滚动容器识别，实现了流畅的半屏交互体验。

---

## 1. 组件定位与能力

- **底部浮动面板**：固定在视口底部，通过 `transform: translateY` 控制露出高度。
- **多档位高度**：通过 `anchors` 定义一组高度阈值，滑动结束后自动吸附到最近档位。
- **手势驱动**：支持拖拽、快速滑动、边界阻尼、内部滚动内容联动。
- **安全区适配**：`safeAreaInsetBottom` 处理 iPhone 底部安全区。
- **受控/非受控兼容**：提供 `defaultAnchorsIndex` 设置初始档位，并通过事件暴露当前高度。

---

## 2. 核心 Props 设计

| Prop | 作用 |
|------|------|
| `anchors` | 高度阈值数组，例如 `[100, 屏幕宽度的 60%]` |
| `defaultAnchorsIndex` | 默认展示哪个档位 |
| `duration` | 非拖拽状态下吸附动画时长 |
| `contentDraggable` | 内部滚动区域是否也能拖面板 |
| `scrollIds` | 内部滚动容器 id 数组，用于解决「内容滚动 vs 面板拖动」冲突 |
| `safeAreaInsetBottom` | 底部安全区 |
| `onHeightChange` | 档位变化回调 |
| `onDynamicHeightChange` | 拖拽过程中实时高度变化回调 |

---

## 3. 关键实现思路

### 3.1 双变量保存高度，避免 React 批量更新带来的时序问题

```tsx
const [sheetHeight, setSheetHeight] = useState(anchors[anchorsIndex]);
const realSheetHeight = useRef(sheetHeight);
```

- `sheetHeight`：用于视图渲染。
- `realSheetHeight`：用于 `touchStart / touchMove / touchEnd` 中实时读取当前高度，避免 `setState` 异步导致拿不到最新值。

### 3.2 位移动画通过 `translateY` 实现

```tsx
transform: `translateY(calc(100% + ${-sheetHeight}px))`
```

- 面板高度固定为最大档位高度，通过向下平移自身高度的一部分来模拟「露出高度」。
- 拖拽过程中 `transition: none` 保证跟随手指；松手后恢复 `transition` 做吸附动画。

### 3.3 边界阻尼 & 最近档位吸附

- `ease()` 函数：当拖拽超过 `anchors` 最大/最小值时，施加 **0.2 倍阻尼**，增强手感。
- `closest()` 工具函数：松手后计算距离当前高度最近的 anchor，自动吸附。

### 3.4 快速滑动识别

借助 `@ali/rxpi-hooks` 的 `useTouch` 判断 `isFast` / `isScrollUp` / `isScrollDown`：

- 快速上滑 → 直接展开到最大档位。
- 快速下滑 → 若内部滚动区域未回到顶部，先滚内容；到顶后再收层面板。

---

## 4. 最复杂的点：内部滚动与面板拖拽的冲突处理

这是该组件最容易被追问的部分，逻辑集中在 `onTouchmove`：

1. **识别当前触摸的滚动区域**：通过 `scrollIds` 找到触发事件的滚动容器。
2. **记录最大滚动偏移**：`maxScroll.current` 用于判断手指滑入面板时，内容是否已经在滚动。
3. 分情况处理：
   - 面板未展开到最大高度时，**禁止内部滚动，优先拖面板**。
   - 面板已到最大高度且内容在顶部时，向下滑动才触发面板收起。
   - 内容 `scrollTop > 0` 时，向下滑动**先滚内容，不拖面板**。
   - 其他情况 `preventDefault` 阻止默认滚动，保证面板跟随手指。

---

## 5. 可扩展/可讲亮点

- **多端兼容**：Rax + rax-view，一套代码跑浏览器和 Weex。
- **性能优化**：拖拽时移除 transition、使用 `will-change: transform`、通过 `ref` 减少重渲染。
- **嵌套滚动解耦**：通过外部传入 `scrollIds`，把「谁是滚动容器」的决定权交给业务方，组件本身不依赖具体子组件。
- **默认兜底**：`anchors` 不足两个时，内部会自动补齐 `[min, max]`，避免业务传空数组崩溃。

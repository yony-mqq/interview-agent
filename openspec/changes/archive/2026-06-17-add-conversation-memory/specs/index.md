# 需求规格总览

本目录存放「增加对话记忆管理」变更的详细需求规格。

## 规格清单

| 文件 | 说明 |
|------|------|
| `index.md` | 本文件，规格总览 |
| `user-identity.md` | 用户身份识别方案 |
| `data-model.md` | 数据库表结构与字段定义 |
| `api.md` | RESTful API 接口规格 |

## 关键非功能需求

1. **数据持久化**：服务端数据库，刷新不丢失。
2. **轻量部署**：数据库为单文件 SQLite，便于备份和迁移。
3. **向后兼容**：`/api/chat` 接口兼容旧请求格式（不传 `conversation_id` 时自动创建新会话）。
4. **隐私安全**：`user_id` 仅用于区分会话，不关联真实身份信息。

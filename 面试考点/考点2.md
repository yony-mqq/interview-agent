## 二、针对性面试准备策略

**实战演练**

- 去GitHub找LangChain或AutoGen开源项目
- 自己写简单的"文档问答助手"

### 2. 强化"后端/RAG"知识

**复习API设计**

- RESTful或GraphQL
- 流式传输（Server-Sent Events/WebSockets）
- 前端必须精通SSE

**理解RAG流程**

- 用户提问 → Embedding → 向量库检索 → 组装Prompt → LLM回答 → 前端渲染
- 能清晰讲出这个流程

### 3. 整理"AI落地"的项目故事

**如果没有工作经验**

- 强调Side Project
- 例如："我用Next.js + LangChain做了一个xxx工具，解决了xxx问题"

**如果有工作经验**

- 即使是写普通的CRUD，也要强调AI辅助过程
- 例如："我使用Cursor重构了旧代码，效率提升了50%"

### 4. 刷题方向调整

**算法题**

- 保持手感即可
- 不需要刷太难的竞赛题

**系统设计题**

- 重点练习"设计一个AI聊天应用"
- 练习"设计一个RAG系统"
- 考虑并发、Token限制、上下文窗口管理、流式响应处理

## 三、面试官可能提出的问题

### 1. 架构与编排问题

**问题：** "这个面试助手的整体架构是怎样的？你是如何处理'听题'、'思考'、'生成回答'这几个步骤的？是简单的Chain调用，还是用了类似LangGraph的状态机？"

**回答策略：**

- 设计基于状态机（StateMachine）的Workflow
- 感知层：前端通过WebSocket实时接收语音转文字流
- 规划层（Router）：用轻量级模型判断问题类型
- 执行层：技术题检索知识库，行为题检索经历库
- 生成层：组装上下文+问题+人设Prompt，流式输出

### 2. 上下文与记忆管理问题

**问题：** "面试过程中，上下文会越来越长。你是如何管理Token消耗的？如果面试官追问之前的细节，你的Agent能记住吗？"

**回答策略：**

- **短期记忆：** 保留最近5-10轮对话在ContextWindow中
- **长期记忆：** 核心项目经历、技能点做Embedding存入向量数据库
- 当追问细节时，先用关键词去向量库检索相关详情，动态注入到Prompt中

### 3. 延迟优化与用户体验问题

**问题：** "大模型生成速度通常比较慢，作为面试辅助工具，延迟太高就没意义了。你在前端和后端做了哪些优化来降低首字延迟（TTFT）？"

**回答策略：**

- **传输层：** 全程使用SSE流式传输
- **前端渲染：** 自定义Markdown解析器，支持打字机效果
- **策略层：** 简单问题本地秒回，复杂问题才走云端大模型

### 4. 评测与迭代问题

**问题：** "你怎么知道你的Agent回答得好不好？有没有什么量化指标？如果它回答错了，你怎么修复？"

**回答策略：**

- 收集50道高频面试题和"满分回答"作为GoldenDataset
- 修改Prompt或更换模型后，跑自动化脚本，让GPT-4o打分
- 前端加"点赞/点踩"按钮，收集用户真实反馈数据

### 5. 防幻觉与安全问题

**问题：** "如果面试官问了一个你完全不知道的技术，你的Agent会胡编乱造吗？你是怎么防止幻觉的？"

**回答策略：**

- 在SystemPrompt里加严格的防御性指令
- 如果检索不到相关信息，直接告诉用户不确定
- 对于生成的代码或关键技术点，强制要求输出引用来源（Citation）

## 四、简历亮点包装建议

### 项目名称：AI智能面试教练（Personal Interview Agent）

**核心架构：** 基于LangGraph构建多步推理工作流，实现了意图识别、知识库检索（RAG）、答案生成的自动化编排。

**全栈开发：** 前端采用React + TypeScript实现流式渲染与语音交互；后端使用Node.js/Python搭建MCP Server，连接个人Notion/Obsidian知识库作为外部工具。

**性能优化：** 通过滑动窗口算法管理上下文，结合向量检索，将Token消耗降低40%，首字延迟控制在800ms以内。

**效果评估：** 构建了包含50+题目的自动化评测集（Eval Set），利用LLM-as-a-Judge机制持续优化Prompt，回答准确率提升至90%。

## 五、总结与建议

### 你的优势

- 前端在AI应用层（UI/UX、交互体验、流式响应展示）有天然优势
- 现在的AI产品非常卷体验，这正是你的机会

### 你的劣势

- 对模型底层、Python生态、后端架构可能不熟悉

### 行动清单

1. **立刻上手LangChain/LangGraph：** 哪怕只是写几个Demo
2. **学习MCP协议：** 这是一个区分度很高的新技术点
3. **准备一个全栈Demo：** 结合React/Vue + Node.js + LLM API，做一个能实际运行的Agent应用
4. **熟悉SSE（Server-Sent Events）：** 这是前端对接LLM的标准姿势
